How it works

Two editors, one expression

Maya stays the source of truth. The bridge keeps VS Code in step with it.

Edit

Change it in VS Code

Open an object's expressions from the tree, edit with MEL highlighting, and press Ctrl+S to push the change into Maya as a single undoable step.

Sync

See Maya's edits within a second

Changes made in the Expression Editor show up in VS Code. A clean editor reloads by itself. A dirty one asks before anything is overwritten.

Check

Find errors on the right line

Maya's syntax and runtime errors appear in Problems. Maya keeps the last working version, so a typo never breaks the scene.

VS Code · pCube1 · translateY
1  float $t = `time`;
2  translateY = sin($t * 2) * 3;
3  translateX = $t *  ;
Problems · source Maya
Line 3   Syntax error
         Maya kept the previous expression
⚠Syntax error on line 3. The scene still runs on the last valid version.
Install

Set up in about two minutes

The installer copies the Maya module and the VS Code extension into place.

  1. Download and unzip

    Save ExpressionBridge-1.0.0.zip and extract it to any folder, such as Downloads.

  2. Run the installer

    Double-click Install.bat. It copies the Maya module into your Documents\maya\modules folder and installs the VS Code extension.

  3. Start Maya

    Start Maya, or restart it if it was open. An Expression Bridge menu appears in the main menu bar.

  4. Connect VS Code

    If VS Code asks, click Restart Extensions. Then click the M icon in the activity bar.

Verify the download first if you like. In PowerShell, run Get-FileHash ExpressionBridge-1.0.0.zip -Algorithm SHA256 and compare the result with the value in ExpressionBridge-1.0.0.zip.sha256.

If Install.bat can't find VS Code, or PowerShell scripts are blocked, the Troubleshooting section below shows the manual steps.

Everyday tasks

Most of the time you only need the tree, the editor and the Problems panel.

Troubleshooting

The status bar shows Maya with a broken plug

Make sure Maya is open, then choose Expression Bridge, then Start. VS Code retries every 3 seconds. Click the status bar item to retry now and see the error.

There is no Expression Bridge menu in Maya

Check that Documents\maya\modules\ExpressionBridge.mod exists, then restart Maya.

I have two copies of Maya open

VS Code connects to the Maya that started its bridge last. In the one you want, choose Stop and then Start.

Install.bat says the code command wasn't found

Install the extension by hand. In VS Code, open Extensions, click ... at the top right, choose Install from VSIX..., and pick vscode\expression-bridge-1.0.0.vsix from the unzipped folder.

My company blocks PowerShell scripts

Drag maya\drag_and_drop_install.py from the unzipped folder into a Maya viewport. Then install the extension from the VSIX, as described above.
