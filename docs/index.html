Expression Bridge

Edit Maya expressions in VS Code. Saving updates Maya, edits in Maya appear in VS Code, and Maya's errors show in the Problems panel.

Version 1.0.0. Needs Windows 10 or 11, Maya 2024, 2025 or 2026, and VS Code 1.90 or newer.

Install

  1. Unzip ExpressionBridge-1.0.0.zip anywhere.
  2. Double-click Install.bat. It copies the Maya module into Documents\maya\modules and installs the extension into VS Code.
  3. Start Maya, or restart it if it was open. An Expression Bridge menu appears in the main menu bar.
  4. In VS Code, click Restart Extensions if prompted, then click the M icon in the activity bar.

You can delete the unzipped folder afterwards. Everything is copied into place.

Other ways to install

  • From VS Code alone: install the VSIX, then run Maya: Install Bridge into Maya from the Command Palette and restart Maya. Maya: Uninstall Bridge from Maya removes it again.
  • Maya only, without a restart: drag maya\drag_and_drop_install.py into a Maya viewport. It installs and starts the bridge right away.
  • VS Code only: open Extensions, click ... at the top right, choose Install from VSIX..., and pick vscode\expression-bridge-1.0.0.vsix.
  • From PowerShell, with options: installer\install.ps1 [-SkipMaya] [-SkipVSCode] [-ModulesDir <folder>] [-CodeCli <path to code.cmd>]. If you set MAYA_APP_DIR, the module goes into %MAYA_APP_DIR%\modules.

Update

Unzip the new version and run Install.bat again, then restart Maya and click Restart Extensions in VS Code.

Uninstall

Double-click Uninstall.bat, or run installer\install.ps1 -Uninstall. This removes the module and the .mod file from Maya's modules folder, and the extension from VS Code.

Check the download

In PowerShell, run Get-FileHash ExpressionBridge-1.0.0.zip -Algorithm SHA256 and compare the result with ExpressionBridge-1.0.0.zip.sha256.

Use

Edit an expression

  1. Click the M icon in VS Code. Objects lists every object that has expressions.
  2. Click an expression and edit it.
  3. Press Ctrl+S. Maya updates.

To undo the whole save, press Ctrl+Z in Maya.

Fix an error

Maya's errors appear in the Problems panel on the line they came from. After a syntax error, Maya keeps the last working version of the expression until you save a fixed one.

Edit in Maya as well

Changes made in Maya, for example in the Expression Editor, appear in VS Code within about a second. If you have unsaved changes to the same expression, your next save is refused so that it can't overwrite Maya's edit. Revert the file in VS Code to load Maya's version.

Change an expression's settings

The Settings panel under the tree shows Convert Units, Always Evaluate and the plugs the expression drives. Changes apply at once. You can also right-click an expression to set Convert Units or Always Evaluate.

Work with selection

To select an object in Maya, hover it in the tree and click the target icon. The tree also highlights Maya's selection. To turn that off, use the setting expressionBridge.followMayaSelection.

Particle expressions

Creation, runtime before dynamics and runtime after dynamics show as separate entries under the particle shape. Maya rewrites their text when saved (lifespanPP becomes particleShape1.lifespanPP), and the editor reloads with Maya's version.

Start and stop the bridge

The bridge starts with Maya. To control it, use Expression Bridge > Start, Stop or Status in Maya's menu bar.

How it works

There are two parts: a module that runs inside Maya, and an extension in VS Code. Expressions stay in your Maya scene. VS Code opens them straight from Maya, so there are no script files to keep in step.

Connecting. When the bridge starts, Maya opens a server on 127.0.0.1 and writes its port and a random token to %LOCALAPPDATA%\ExpressionBridge\session.json. VS Code reads that file, connects, and sends the token with every request. The server only listens on this computer, so no firewall rule is needed.

Saving. VS Code sends the new text to Maya as one undoable edit. Maya refuses it if the expression has changed since you opened it. Any errors Maya prints during the edit go back to the Problems panel.

Staying in sync. Maya checks its expressions for changes every second and tells VS Code about any it finds. The check runs on a timer because editing in the Expression Editor doesn't fire an event.

Troubleshooting

The status bar shows Maya with a broken plug

Make sure Maya is open, then choose Expression Bridge > Start in Maya. VS Code retries every 3 seconds. Click the status bar item to retry now and see the error.

There's no Expression Bridge menu in Maya

Check that Documents\maya\modules\ExpressionBridge.mod exists, then restart Maya. In Maya's Script Editor, cmds.moduleInfo(listModules=True) should include ExpressionBridge.

Two copies of Maya are open

VS Code talks to the one that started its bridge last. In the one you want, choose Expression Bridge > Stop, then Start.

Install.bat says the code command wasn't found

Install the extension from the VSIX by hand, as described under VS Code only.

Your company blocks PowerShell scripts

Drag maya\drag_and_drop_install.py into a Maya viewport, then install the extension from the VSIX.
